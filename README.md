# 🐟 Aquatic Ascent

_Aquatic Ascent_ is an Android game built with **Java** and **XML** in **Android Studio**. Guide a fish through dynamically generated obstacles in a smooth, responsive underwater adventure.

## 🚀 Features
- Procedural obstacle generation
- Real-time collision detection
- Smooth controls and animated UI

## 🛠 Built With
- Java & XML
- Android Studio
